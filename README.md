# Open-house 2026 website 

Web app to help users find different booths using a directory & maps and make it fun to find booths by allowing them to collect stickers at each stall they visit.

### Features Implemented:
- Home Page with Help directory
- Schedule Page
- Booth information page
- Maps with event order
- Virtual Passport page with stamps

### Tech Stack:
- React 19 + TypeScript 6 + Vite 8

### Current update:
- More info on home page now, with live countdown
- Maps include floor plans and paths for MECE-1,2 and 3
- Passport QR collection and idempotency check complete
- LocalStorage persistence included.
